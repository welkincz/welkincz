### Building

**[Orbit](https://github.com/welkincz/Orbit)** · [orbit.charliebuild.com](https://orbit.charliebuild.com)
A local-first graph of the people you work with, so the context of a
relationship is already there when the conversation starts. The published
copy runs on fictional seed data; a real vault stays on the disk it was
written on. *Next.js, TypeScript, 224 tests.*

Five days on Cape Breton as one HTML file. No build step and no
dependencies, so it still opens on a phone with no signal.
